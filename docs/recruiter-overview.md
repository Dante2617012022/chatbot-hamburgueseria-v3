# Vista rápida para reclutadores

## Qué demuestra este proyecto

- Automatización aplicada a un negocio real.
- Gestión de estados y flujos conversacionales.
- Integración con WhatsApp, Mercado Pago, SQLite e IA.
- Controles de seguridad implementados sobre entradas, secretos, webhooks y abuso.
- Uso limitado y validado de IA para evitar decisiones sensibles automáticas.
- Pruebas automatizadas y documentación de riesgos residuales.

## Tecnologías

Node.js, JavaScript, Express, SQLite, Baileys, Mercado Pago, OpenAI, Zod y Pino.

## Aporte del autor

Diseño de arquitectura, implementación del flujo de pedidos, integración de servicios, controles de seguridad, pruebas, documentación y mejora iterativa del producto.

## Estado

Proyecto en evolución y preproducción. La documentación distingue controles implementados de mejoras pendientes, evitando presentarlo como una solución productiva completamente cerrada.
