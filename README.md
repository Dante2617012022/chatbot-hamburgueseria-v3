# Chatbot Hamburgueseria V3

Sistema modular para tomar pedidos por WhatsApp, gestionar carrito, validar productos, integrar pagos con Mercado Pago y enviar pedidos al local.

## Objetivo

Construir una versión productiva, modular y segura del chatbot gastronómico.

## Estructura

- `src/bot`: conexión WhatsApp y manejo de mensajes.
- `src/orders`: lógica de pedidos, carrito y estados.
- `src/menu`: menú editable, productos y búsqueda.
- `src/payments`: integración con Mercado Pago.
- `src/ai`: interpretación de mensajes e IA.
- `src/storage`: base de datos y repositorios.
- `src/admin`: comandos administrativos.
- `src/config`: configuración.
- `src/utils`: utilidades generales.
- `data`: menú y base de datos local.
- `tests`: pruebas automatizadas.

## Estado

Proyecto iniciado desde cero para construir una versión productiva.
